# Каталоги переводов

Здесь лежат файлы `Strings.<код-культуры>.json` — по одному на язык.
Файлы читает `ProTranslate.SourceGenerator` на этапе сборки (см. `AdditionalFiles`
в `MouseLabAvaloniaApp.csproj`) и генерирует по ним:

| Что генерируется | Назначение |
|---|---|
| `ProTranslateKeys` | константы ключей, например `ProTranslateKeys.AppGreeting` |
| `ProTranslateStrings` | типизированные свойства для привязки: `{Binding Strings.AppGreeting}` |
| `ProTranslateGeneratedTranslationProvider` | провайдер, отдающий значения в рантайме |
| `ProTranslateProviderManifest` | список ключей и культур для упаковки и диагностики |

Значения компилируются **в сборку**, поэтому в рантайме файлы не читаются
(в том числе поэтому каталоги исключены из `AvaloniaResource`).
Правка перевода требует пересборки проекта.

## Соглашения

**Культура берётся из имени файла.** Суффикс после `Strings.` — это код языка
в формате BCP-47: `en-US`, `ru-RU`, `de-DE`. Добавить язык = создать
`Strings.de-DE.json` с тем же набором ключей; правки в C# не нужны.

**Вложенность превращается в точки.** Объект `"App"` с полем `"Title"` даёт
ключ `App.Title`. Плоские ключи с точками тоже допустимы
(`"Orders.EmptyState": "..."`), их можно смешивать.

**Плейсхолдеры.** `{0}`, `{1}` подставляются через `Translations.Format(...)`
в коде. Число и порядок плейсхолдеров должны совпадать во всех культурах —
иначе анализатор `PTA002` сообщит о несовпадении.

**Ключи должны быть одинаковыми во всех файлах.** Если в `Strings.pl-PL.json`
не хватает ключа, который есть в `Strings.en-US.json`, анализатор `PTA003`
выдаст предупреждение о пробеле в переводе, а в рантайме этот ключ молча
покажется на английском.

**Пустая строка — валидный перевод** и означает «намеренно пусто».
Незаполненный ключ, наоборот, вернёт в интерфейсе сам ключ
(например `App.Greeting`) — это основной признак опечатки в имени.

## Почему здесь нет комментариев

Формат JSON не поддерживает комментарии, и `ProTranslate.SourceGenerator`
отверг бы такой файл с `PTSG001`. Поэтому соглашения описаны здесь,
а не внутри каталогов.
